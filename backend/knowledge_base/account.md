# Password reset

Select Forgot password on the sign-in page and enter the account email. The reset link expires after 30 minutes and can be used once. Check spam or promotions folders if the email does not arrive within five minutes. Requesting a new link invalidates the previous link.

# Account security

Support will never ask for a password, one-time security code, full payment-card number, or government identification number in chat. If suspicious activity is detected, reset the password immediately, enable two-factor authentication under Account > Security, and contact support.

# Email address changes

After signing in, go to Account > Profile > Email. Enter the new address and confirm it using the verification message sent to that address. If the customer cannot access the account, a human specialist must complete identity verification.
