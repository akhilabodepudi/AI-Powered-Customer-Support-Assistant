# Return eligibility

Most unused items in original condition can be returned within 30 calendar days of delivery. Final-sale items, personalized products, opened hygiene products, and digital gift cards are not returnable. A return must include its original accessories and packaging.

# Start a return

Go to Account > Orders, select the item, and choose Start a return. Select a reason and download the prepaid shipping label. Drop off the package with the carrier shown on the label within seven days. One prepaid return label is provided per eligible order.

# Refund timing

After the warehouse receives and inspects a return, refunds are approved within two business days. Banks usually post the refund to the original payment method within five to ten business days. Original express-shipping charges are not refundable unless the item was defective or the wrong item was sent.

# Exchanges

Direct exchanges are not currently supported. Return the eligible item for a refund and place a new order for the replacement.
